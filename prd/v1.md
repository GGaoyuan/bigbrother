## 1. 产品概述

BigBrother 是一个面向个人市场研究的金融数据工作台，包含 Web 前端、桌面端和 FastAPI 后端。Webfront 提供行情、复盘和数据浏览界面；Desktop 提供独立的行情图表与资金流工具；Backend 按数据层和 API 层组织，向前端提供市场数据接口。

## 4. Backend

### 4.1 架构与数据源规则

- [x] Backend 只分为数据层和 API 层：数据层获取原始数据；API 层调用数据层、处理数据逻辑并返回结果。
- [x] 项目数据源选型按 `mootdx > 其他通达信 Python 库 > akshare > 其他现成数据 Python 库` 执行；均无法满足时，先说明排查结果并取得用户明确同意，再自行写爬虫，包括自行请求官网 JSON 接口。规则持久化于根目录 `AGENTS.md` 和后端代理配置，适用于项目新会话；个股原始日线、60 分钟和 5 分钟按任务约定在通达信不可用时尝试 a-stock-data，1 分钟适配器核验了 mootdx、easy_tdx、AKShare 新浪和 a-stock-data。
- [x] 依赖清单以 FastAPI、Uvicorn、Pandas、mootdx、AKShare 为当前基础依赖；AKShare 固定为已验证的 1.20.37 版本。

### 4.2 当前接口

- [x] 所有 API 成功及错误响应统一采用 `{ "code": ..., "message": "...", "data": ... }` 结构；由共享 response 模块构造，并统一包装 HTTP、参数校验和未处理异常。
- [x] `POST /api/v1/market/index/hist`：从通达信获取上证指数或沪深300日线 K 线，不加缓存。请求体支持 `code`（`000001.SH` 上证指数，默认值；`000300.SH` 沪深300）；所有支持的指数统一请求最近 800 根，不暴露条数参数，实际返回条数以数据源为准；响应按交易日期升序排列，含交易日期、开高低收、成交量、成交额、涨跌幅。
- [x] `POST /api/v1/capital/margin`：通过 AKShare 获取沪深两市每日融资融券汇总，不自行抓取、不缓存。可传 `date` 查询指定日期；默认在最近 60 个自然日内返回两市均有数据的最新交易日，响应同时包含沪市、深市、同日合计和来源信息。金额统一为元、数量为股/份，保留深市原始百万级精度说明；融资偿还额由前一交易日余额推算并标为估算，缺前日数据时为 `null`。非交易日或两市未齐返回空列表，数据源异常返回 502。已用真实数据验证，详见 `docs/backend/backend-margin-api.md`。
- [x] 指数日 K 和两融 API 无需登录；直接运行 Backend 默认监听 `127.0.0.1:8000`，接受本地 Webfront 开发端口发起的请求。
- [x] `/api/v1/stocks/{symbol}` 提供真实个股信息、前复权 K 线和基于 1 分钟 K 线的成交量分布估算。个股 K 线采用 `POST /klines`，从 JSON 请求体接收周期、区间和分页参数。不复权 K 线优先尝试通达信，近期可用新浪原生 1 分钟线，较早区间由 easy_tdx MAC 行情按选区分页获取，腾讯作为滚动窗口备用来源。各周期使用同一通达信除权事件版本，按个股代码查询除权记录。 通达信连接失效时会限次重连。接口附数据质量、实际分钟区间和来源。原有分笔查询接口单独提供。详见 `docs/backend/backend-stocks-api.md`。
- [x] 旧 `/api/v1/market/profile/history` 和 `/api/v1/market/profile/trades` 为显式模拟接口，真实成交量分布页使用 `/api/v1/stocks`。
- [x] Backend 在控制台输出带请求 ID 的 JSON 日志，记录请求路径、参数、Provider 尝试和失败原因、选中来源、缓存命中、状态码、耗时和完整响应，敏感字段脱敏。
- [ ] 将此接口及后续通达信数据接口接入 Webfront / Desktop，并完成运行环境下的数据源验证。
