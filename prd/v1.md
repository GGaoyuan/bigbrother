# BigBrother 项目产品需求文档

> 更新日期：2026-11-09
> 本文档是项目功能目录与当前状态记录。`[x]` 表示当前代码中已有实现，`[ ]` 表示待完成；“原型”表示仅有界面或模拟数据，尚未接入真实数据/完整流程。

## 1. 产品概述

BigBrother 是一个面向个人市场研究的金融数据工作台，包含 Web 前端、桌面端和 FastAPI 后端。Webfront 提供行情、复盘和数据浏览界面；Desktop 提供独立的行情图表与资金流工具；Backend 按数据层和 API 层组织，向前端提供市场数据接口。

## 4. Backend

### 4.1 架构与数据源规则

- [x] Backend 只分为数据层和 API 层：数据层获取原始数据；API 层调用数据层、处理数据逻辑并返回结果。
- [x] 行情数据源限定为通达信相关库，优先使用 `mootdx`；不得引入其他行情数据源。
- [x] 依赖清单以 FastAPI、Uvicorn、Pandas、mootdx 为当前基础依赖。

### 4.2 当前接口

- [x] 所有 API 成功及错误响应统一采用 `{ "code": ..., "message": "...", "data": ... }` 结构；由共享 response 模块构造，并统一包装 HTTP、参数校验和未处理异常。
- [x] `POST /api/v1/market/index/hist`：获取上证指数日线 K 线。请求体支持 `limit`（默认 500，范围 1–800）；响应含交易日期、开高低收、成交量、成交额、涨跌幅。
- [x] `POST /api/v1/auth/login`：手机号和密码登录；当前返回固定模拟用户资料与 token，不校验真实账号。
- [x] `POST /api/v1/app/config`：获取数据、AI、页面三个工作区的 ID 与名称。
- [x] `POST /api/v1/workspace/data`：返回数据工作区分类；支持带指数系列与图表类型的指标配置，以及只有指标列表的融资融券配置，当前数据为模拟目录。
- [x] `POST /api/v1/workspace/pages`：获取页面工作区路由清单及其工作区 ID。
- [x] 除登录接口外，所有 API 默认要求有效 Bearer token；缺少 token 返回“未登录”，错误 token 返回“token错误”。
- [x] Backend 为每个 HTTP 请求输出 pretty-printed 日志，包含请求方法、路径、路径/查询参数、请求体、响应状态、响应数据和耗时；密码、token、授权信息等敏感字段脱敏。
- [ ] 将此接口及后续通达信数据接口接入 Webfront / Desktop，并完成运行环境下的数据源验证。
