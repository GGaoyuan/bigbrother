# BigBrother 项目产品需求文档

> 更新日期：2026-11-26
> 本文档是项目功能目录与当前状态记录。`[x]` 表示当前代码中已有实现，`[ ]` 表示待完成；“原型”表示仅有界面或模拟数据，尚未接入真实数据/完整流程。

## 1. 产品概述

BigBrother 是一个面向个人市场研究的金融数据工作台，包含 Web 前端、桌面端和 FastAPI 后端。Webfront 提供行情、复盘和数据浏览界面；Desktop 提供独立的行情图表与资金流工具；Backend 由 API、Service、Model、Data、Core 五层组成，向前端提供市场数据接口。

## 4. Backend

### 4.1 架构与数据源规则

- [x] API 每个接口独立文件，负责 HTTP 请求和响应。Service 组织业务并依赖 Model 的取数协议。Data 实现协议，负责获取与标准化。Core 提供日志、缓存、异常和时间工具，`main.py` 注入依赖。
- [x] 优先检查 `mootdx > 其他通达信 Python 库 > 其他现成数据 Python 库`。只有用户明确授权的任务才能使用 AKShare。自行写爬虫前按 `AGENTS.md` 取得用户同意。
- [x] 个股信息和图表行情优先尝试通达信公共主站，其次腾讯。1 分钟行情依次尝试通达信公共主站、easy_tdx MAC、腾讯，由 `exchange-calendars` 的 XSHG 日历提供交易日校验。

### 4.2 当前接口

- [x] `backend/app/api/stocks/` 按接口独立定义三个业务路由。默认监听 `127.0.0.1:8000`，允许本地 Webfront 开发端口请求，接口无需登录。
- [x] 所有 API 成功及错误响应统一采用 `{ "code": ..., "message": "...", "data": ... }` 结构；由共享 response 模块构造，并统一包装 HTTP、参数校验和未处理异常。
- [x] `GET /api/v1/stocks/{symbol}` 查询真实个股信息。
- [x] `POST /api/v1/stocks/{symbol}/klines` 查询前复权日线、60 分钟和 5 分钟 K 线，请求体支持周期、区间和分页参数。
- [x] `POST /api/v1/stocks/{symbol}/volume-profile` 以通过校验的原生 1 分钟 K 线估算成交量分布，返回实际分钟区间、来源和数据质量。图表和分布使用同一通达信除权事件版本。详见 `docs/backend/backend-stocks-api.md`。
- [x] Backend 在控制台输出带请求 ID 的 JSON 日志，记录请求路径、参数、Provider 尝试和失败原因、选中来源、缓存命中、状态码、耗时和完整响应，敏感字段脱敏。
