# BigBrother 项目产品需求文档

> 更新日期：2026-11-06
> 本文档是项目功能目录与当前状态记录。`[x]` 表示当前代码中已有实现，`[ ]` 表示待完成；“原型”表示仅有界面或模拟数据，尚未接入真实数据/完整流程。

## 1. 产品概述

BigBrother 是一个面向个人市场研究的金融数据工作台，包含 Web 前端、桌面端和 FastAPI 后端。Webfront 提供行情、复盘和数据浏览界面；Desktop 提供独立的行情图表与资金流工具；Backend 按数据层和 API 层组织，向前端提供市场数据接口。

## 4. Backend

### 4.1 架构与数据源规则

- [x] Backend 只分为数据层和 API 层：数据层获取原始数据；API 层调用数据层、处理数据逻辑并返回结果。
- [x] 行情数据源限定为通达信相关库，优先使用 `mootdx`；不得引入其他行情数据源。
- [x] 依赖清单以 FastAPI、Uvicorn、Pandas、mootdx 为当前基础依赖。

### 4.2 当前接口

- [x] `POST /api/v1/market/index/hist`：获取上证指数日线 K 线。请求体支持 `limit`（默认 500，范围 1–800）；响应含交易日期、开高低收、成交量、成交额、涨跌幅。
- [ ] 将此接口及后续通达信数据接口接入 Webfront / Desktop，并完成运行环境下的数据源验证。
